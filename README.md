# Prom.ua to WooCommerce Sync

Інструмент на Python для автоматичної синхронізації каталогу товарів, категорій та зображень із фіду/вивантаження **Prom.ua** в інтернет-магазин на **WooCommerce**.

---

## 📌 Основні можливості

- **Синхронізація категорій та товарів**: Автоматичний імпорт та оновлення структури категорій та карток товарів.
- **Діагностика осиротілих записів**: Скрипти для виявлення та аналізу втрачених або застарілих категорій/товарів (`check_orphans.py`, `diagnose_orphans.py`).
- **Парсинг та обробка медіа**: Оптимізований парсер зображень категорій та товарів.
- **Сповіщення в Telegram**: Інтегрована система сповіщень та команд для моніторингу процесу синхронізації у реальному часі.
- **Захист від збоїв**: Вбудована обробка помилок мережі та стабілізація підключень.
